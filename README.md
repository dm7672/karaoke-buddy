# Karaoke Buddy

Android-приложение для караоке на любой песне. Пользователь вставляет ссылку на видео YouTube
или вводит название песни, а приложение готовит из неё инструментальную версию (минусовку)
и караоке: текст, в котором каждое слово подсвечивается в такт. Поддерживаются песни на русском
и английском.

Учебный проект курса Android-разработки (УрФУ, осень 2026).

## Как это работает

```
Телефон (Kotlin, Compose)                 Бэкенд (Python, GPU)
──────────────────────────                ─────────────────────────────────────────
ссылка YouTube / название песни  ──────▶  получить аудио
/ свой аудиофайл                          отделить вокал от минуса
                                          найти синхронный текст (LRCLIB)
                                          выровнять слова по вокалу
минус + караоке                  ◀──────  минус + текст с таймингами слов
```

Тяжёлая обработка (отделение вокала, выравнивание текста) идёт на сервере: на телефоне она слишком
медленная. Методы выравнивания сравниваются в прототипе [`../lyrics-lab`](../lyrics-lab/README.md).

## Основная функция

**По ссылке на видео YouTube или по названию песни пользователь получает минусовку и караоке под неё.**

- Вход: ссылка на видео YouTube или поиск «исполнитель — название».
- Пока песня обрабатывается, на экране виден статус: в очереди, обрабатывается, готова
  или ошибка с причиной.
- Результат — караоке-плеер: играет минусовка, текст подсвечивается по словам; текущая строка
  крупно, следующая под ней.

## Дополнительные функции

### Свой аудиофайл
- Сделать караоке из своего аудиофайла (mp3, m4a, wav): файл загружается на сервер,
  дальше — та же обработка.
- Если синхронный текст песни не нашёлся, пользователь вставляет текст сам, а тайминги
  расставляет сервер.

### Библиотека песен
- Все обработанные песни — в одном списке.
- Удалить, переименовать, отметить избранной, отсортировать (по дате добавления, по названию).
- Видно, какие песни уже скачаны на телефон и доступны без сети.

### Возможности плеера
- Режим «с подсказкой»: под минус тихо подмешивается основной вокал.
- Пауза, перемотка по строкам текста.
- Подстройка общего сдвига текста относительно музыки, если подсветка отстаёт или спешит.

### Редактирование песни
- Исправить текст: опечатки, пропущенные или лишние строки.
- Поправить тайминги: сдвинуть строку или слово, разметить строку заново нажатиями в такт.
- Правки сохраняются на телефоне и синхронизируются с сервером.

### Офлайн
- Готовая песня (минус, вокал-подсказка, текст с таймингами) скачивается на телефон.
- Библиотека и скачанные песни открываются и играют без сети; правки, сделанные офлайн,
  уходят на сервер при появлении сети.

### Публикация на YouTube
- Собрать караоке-видео: минусовка + текст с подсветкой слов на фоне.
- Выложить его на свой канал YouTube после входа через аккаунт Google (OAuth).
  Название, описание и доступ (открытое, по ссылке, закрытое) задаёт пользователь.

### Общий плейлист
- Общий плейлист для компании: несколько человек по ссылке добавляют в него песни и поют по очереди.
- Добавить существующее видео YouTube (готовое караоке или обычный клип — тогда он обрабатывается
  как в основной функции).
- Добавить своё видео или песню из своей библиотеки.
- Перемешать (shuffle), поменять порядок, удалить, «следующей поставить эту».
- У каждого видео видно, кто его добавил.

## Как закрываются требования курса

Для зачёта по курсу часть дополнительных функций обязательна: библиотека, редактирование и офлайн.

| Требование | Чем закрывается |
|---|---|
| Список + элемент, редактируются оба | библиотека песен (добавить / удалить / переименовать) + песня (текст и тайминги) |
| Работа по сети | бэкенд обработки, синхронизация библиотеки, общий плейлист |
| Офлайн-часть | скачанные песни и библиотека на диске телефона |
| Сложный список (модуль 4) | ячейки разной структуры в зависимости от статуса: прогресс обработки, ошибка с причиной, готовая песня с длительностью и значком «скачано» |
| Усложнение сети: OAuth (модуль 7) | вход через Google для публикации на YouTube |

## Первая домашняя работа: сохранение библиотеки

`Song` описывает песню, `SongJson.kt` переводит её в JSON и обратно,
а `FileStorage` хранит библиотеку в JSON-файле. Пример использования в Android:

```kotlin
val storage = FileStorage(File(context.filesDir, "songs.json"))
storage.load()
storage.add(Song(name = "Песня", status = SongStatus.QUEUED))
storage.save()
```

Список `storage.songs` доступен только для чтения. `add` заменяет песню с тем же
`uid`, `remove(uid)` удаляет её из памяти; для записи изменений нужно вызвать `save()`.
При отсутствии файла `load()` даёт пустую библиотеку. Некорректные элементы массива
пропускаются; повреждение всего JSON-файла и ошибки файловой системы передаются
вызывающему коду. Срок хранения и автоматическое удаление не реализованы.

Единственный тест `SongJsonTest` сохраняет песню в файл, загружает её в другое
хранилище и сравнивает с исходной. Запуск: `gradlew.bat :app:testDebugUnitTest`.

## Технологии

- **Приложение:** Kotlin, Jetpack Compose, корутины и Flow, Room, Media3 (ExoPlayer).
- **Бэкенд:** Python; отделение вокала: audio-separator (BS-RoFormer, MelBand-Roformer Karaoke);
  текст: LRCLIB; выравнивание слов: по результатам `lyrics-lab`; публикация: YouTube Data API.

## Ограничения

- Скачивание аудио с YouTube нарушает условия использования сервиса. Это допустимо для учебного
  проекта, но в стор такое не выложить. Легальный источник аудио — свои файлы пользователя.
- Минусовка чужой песни — производное произведение: выложенное на YouTube видео может получить
  жалобу Content ID или быть заблокировано. Отвечает за публикацию пользователь.
- Тексты песен защищены авторским правом и в репозиторий не кладутся, как и аудио.
- Языки — только русский и английский.
